== Description ==

Q Shop is a modern and fully responsive WooCommerce theme designed for online stores and boutiques. It features a clean layout, performance focused design, and seamless WooCommerce integration to help store owners build professional e commerce websites with ease.

The theme includes customizable hero sections, flexible product layouts, and a streamlined checkout experience. Q Shop is easy to set up using the WordPress Customizer, allowing you to adjust colors, typography, and layout options without touching code. It is accessibility ready and translation ready, making it suitable for a wide range of users and markets.

An optional Q Shop Pro Addon plugin is available, offering additional customization options and extended features.

== Requirements ==

Minimum Requirements:
- WordPress 5.0 or higher
- PHP 7.4 or higher
- WooCommerce 3.0 or higher (for e commerce functionality)

Recommended:
- WordPress 6.0 or higher
- PHP 8.0 or higher
- WooCommerce 6.0 or higher

== Installation ==

1. Upload the `q-shop` folder to the `/wp-content/themes/` directory
2. Activate the theme through the Appearance > Themes menu
3. Install and activate the WooCommerce plugin for shop functionality

After activation, navigate to Appearance > Customize to:
- Upload your logo
- Adjust colors and typography
- Configure header and footer options
- Customize homepage and hero sections
- Manage shop and product layout settings

== Privacy ==

This theme does not collect or store any personal user data.

By default, the theme loads the Inter font family from Google Fonts to display typography. Google Fonts may collect limited technical data related to font requests. You can review Google’s privacy policy here:
https://policies.google.com/privacy

No other third party services or external requests are used by the theme.
